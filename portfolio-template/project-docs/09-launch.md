# Launch go/no-go checklist

Drafted at Station 09 (FlashAttention). Fill it in for Delivery Copilot here; keep the version for your real work project private.

```
LAUNCH GO / NO-GO CHECKLIST

[ ] Evaluation thresholds met on the release candidate (results attached)
[ ] Known failure modes documented, with user-facing mitigations
[ ] Latency p50 / p95 verified at peak load with real prompt lengths
[ ] Cost per request and monthly budget confirmed; alerts configured
[ ] Security, privacy, legal, and responsible-AI reviews signed off
[ ] Monitoring live: sampled quality reviews, errors, latency, cost, user feedback
[ ] Rollback tested; named owner on call for launch week
[ ] Support team briefed; user guidance and feedback channel ready
[ ] Staged rollout plan: cohort, duration, success criteria

Decision: GO / NO-GO     Date:     Approved by:
```
